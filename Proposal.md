## Description
My project will generate a beutiful generated artwork resembling impressionist style of nature 
from  the artist's pov.
It will resemble real artist's painting process in the outdoors to be accurate to the time period

## Features
- Text dialogue
	- After a certain line of code completed, font must be rendered and typed out
- Animated brush strokes
	- Turtle library will probably be imported and must animated brush strokes
- Camera movement
	- For example, when the artist looks up, the background moves the leeast while the
  - canvas moves the most

## Challenges
- Camera denpth of different layers of images moving at different rates
- Turtle library documentation of short brush strokes not shapes with their own properties
- Timing hand animation with the brush strokes (will probably be done last)

## Outcomes
