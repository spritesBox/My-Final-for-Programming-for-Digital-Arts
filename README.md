# Pixel Guessing Game

## https://youtu.be/qV5aotiYnRY

## Github Repository

## A file takes an image from a folder and pixelates it into a new directory; 
## then another file starts the pixel game where the user has to guess what
## object the pixelated image is with multiple choice answers, and if they
## get it wrong, then the game closes, otherwise they go through the whole game 
## and win.
